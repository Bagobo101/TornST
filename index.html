Torn Stock Alerts

Watch any Torn stock and get a notification the moment it crosses a price you set — either direction. Keep this tab open; it checks prices in the background.

1. Connect your API key

Create a "Public Only" key at torn.com → Preferences → API — it's the lowest access level and all this needs. Stored only on this device.

2. Choose which stocks to watch

Connect your API key above to load the stock list.

Prices come straight from the official Torn API using your key, from your browser — nothing is sent anywhere else. High/low shows the range observed since you started tracking each stock here, not its full history. Buy suggestions are a simple heuristic — where the price sits in the range you've seen — not financial advice; the game's stock market can move against any pattern. Alerts fire once per crossing, then re-arm once the price moves back between your thresholds. Closing this tab pauses checking.
